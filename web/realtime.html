A Windows VST, live

A 32-bit Windows VST2 plugin under Wine in Boxedwine's multithreaded build, streamed block by block into an AudioWorklet through /dev/vstbridge: shared WebAssembly memory, woken with Atomics.notify, no main thread on the audio path.
