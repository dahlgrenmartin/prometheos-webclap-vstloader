Windows VST plugins in the browser

Unmodified 32-bit Windows VST2 and VST3 binaries, loaded by a Windows host program running under Wine inside Boxedwine (an x86 emulator compiled to WebAssembly). The host renders a chord and hands the audio back to this page.

How it works: vsthost.exe plays the role of yabridge's Wine-side plugin host. It is a MinGW-built Windows program that loads the plugin with LoadLibrary, drives it through its own ABI (VST2 AEffect or VST3 IComponent/IAudioProcessor) and writes a WAV and a JSON report to C:\vstpoc-out, which this page reads from Emscripten's in-memory filesystem.
