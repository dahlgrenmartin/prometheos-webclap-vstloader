Wrap a Windows plugin

Turns a 32-bit Windows VST2 (.dll) or VST3 (.vst3) plugin into a WebCLAP bundle (.wclap.tar.gz) that buzz-remote installs from its Plugins dialog. The plugin runs in this site's runtime: Wine inside Boxedwine, in the browser.

The first wrap boots the emulator (about 30–60 s). Your file stays in this browser.

This site's own runtime. The host must serve it on its own origin; buzz-remote loads only runtimes it trusts.
